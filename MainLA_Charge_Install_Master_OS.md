## 1. Executive Summary

### 1.1 The Mission

LA Charge Install exists to eliminate the #1 friction point in EV adoption in the Los Angeles metro area: **finding a trustworthy, licensed electrician who will show up, quote fairly, and install correctly.** We don't hold a contractor's license. We don't pull permits. We don't own a single van. We are a **precision acquisition engine** that captures demand at its peak moment of intent and routes it to a curated network of vetted, licensed electrical contractors — collecting a referral fee for every qualified lead we deliver.

### 1.3 The Wedge Strategy

EV charger installations are the **perfect wedge product:**

- **High search volume** — Tesla, Rivian, and Hyundai owners Google this immediately after purchase.

## 2. Entity Architecture — The Core 30

### 2.1 The Entity Strategy Explained

Google's local search algorithm has evolved to think in **entities**, not just keywords. An entity is a real-world thing (a business, a service, a place) with clearly defined attributes. When your **website structure**, **GBP categories**, **NAP citations**, and **on-page content** all tell the same consistent story, Google assigns maximum "Entity Trust" — and rewards you with top placement in both the Map Pack and organic results.

**The Rule:** Every page in the Core 30 must map 1:1 to either a GBP primary/secondary category or a defined service offering. No orphan pages. No keyword-stuffed fluff. Every page is a spoke connected to the hub.

## 3. Technical Stack Plan

### 3.1 Stack Recommendation: Next.js + Tailwind CSS + Vercel

This stack is the gold standard for achieving 100/100 PageSpeed scores with rapid content deployment. Here's the rationale:

| Layer | Technology | Why |
|---|---|---|
| **Framework** | Next.js 15 (App Router) | Static Site Generation (SSG) for all 30 pages. Zero server latency. Built-in image optimization. |
| **Styling** | Tailwind CSS v4 | Utility-first = tiny CSS bundle. No render-blocking stylesheets. |
| **Hosting** | Vercel | Edge network CDN, automatic HTTPS, zero-config deployment, 99.99% uptime SLA |
| **CMS** | Sanity.io (Headless) | Edit city pages and service descriptions without touching code. Webhook-triggered rebuilds. |
| **Forms** | Tally.so or custom API route | Serverless form endpoint. Zero-latency lead capture. Webhooks to email/Slack/CRM. |
| **Analytics** | Vercel Analytics + Plausible | Privacy-safe, CCPA-compliant. No Google Analytics cookie consent bloat. |
| **Schema Markup** | JSON-LD via Next.js `<Script>` | LocalBusiness, Service, FAQPage, BreadcrumbList schemas injected per page |
| **Image Optimization** | next/image + WebP/AVIF | Automatic format selection, lazy loading, CLS prevention |
| **Font Loading** | next/font (local) | Zero layout shift. Fonts served from same origin. |

### 3.2 PageSpeed 100/100 Architecture Rules

```
Performance Budget (Mobile):
├── First Contentful Paint (FCP):    < 1.2s
├── Largest Contentful Paint (LCP):  < 1.8s
├── Total Blocking Time (TBT):       < 50ms
├── Cumulative Layout Shift (CLS):   < 0.05
└── Speed Index:                     < 2.0s

Enforcement Rules:
├── NO third-party scripts in <head> (no GTM, no chat widgets above fold)
├── ALL images use next/image with explicit width/height
├── Fonts preloaded with rel="preload" as="font"
├── Hero image served as WebP, preloaded, fetchpriority="high"
├── Tailwind CSS purged at build time (< 8kb CSS)
└── Core Web Vitals monitored weekly via Vercel Analytics
```

## 4. Conversion Funnel Design

### 4.1 The Funnel Philosophy

Most local service websites have a binary CTA: "Call Now." This creates massive drop-off because users haven't decided yet — they want to *understand the cost first.* Our funnel is built around the **"Instant Estimate" mechanic**: give the user a value (a price range) in exchange for their contact info. This is a fair trade. No friction disguised as value.

### 4.2 The 5-Step Instant Estimate Flow

```

Above-fold CTA: "Get Your Free Estimate — 60 Seconds"
Secondary CTA: "📞 Call Now: (818) XXX-XXXX"

        ↓

──────────────────────────────────────────────────────────────
```

Google's Vicinity Update (2021) and subsequent Helpful Content updates have systematically rewarded pages that demonstrate **genuine local knowledge** over generic content. A page that says "We install EV chargers in Los Angeles" ranks below one that says "Homes in Tujunga and Shadow Hills frequently require a 200-amp panel upgrade before EV charger installation due to the older housing stock built in the 1950s and 60s — we've seen this on nearly every quote in the 91042 zip."

That specificity cannot be faked at scale by a competitor using AI. It is your moat.
